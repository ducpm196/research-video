## 4. Operational Bottlenecks & Strict Constraints
1. **Network Rate Limiting for Edge-TTS**:
   - `lv.py` uses `TTS_CONCURRENCY = 3` and downloads speech from Microsoft Edge TTS.
   - Initial hydration of audio takes ~2-3 minutes per lesson. If temporary socket disconnect occurs, `lv.py` has a 30s automatic backoff retry mechanism.
   - All generated audio is permanently cached in `out/_cache/tts/`. Subsequent builds or re-encodes are instantaneous.
2. **Sequential Builds**:
   - **DO NOT** run concurrent `lv.py render` or `lv.py build` commands. Running multiple headless Edge instances or FFmpeg encoders simultaneously will saturate RAM/GPU and cause crashes.
3. **Git Index Preservation**:
   - Keep ~2,749 staged files untouched. Never execute `git add`, `git commit`, `git reset`, `git checkout`, or `git stash`.
