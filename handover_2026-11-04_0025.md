## 4. Contract Bottlenecks & Operational Constraints
1. **Network Rate Limiting for Edge-TTS**:
   - `lv.py` uses `TTS_CONCURRENCY = 3` and downloads speech from Microsoft Edge TTS.
   - For unrendered lessons (~50 sentences/lesson), TTS cache population takes ~2-3 minutes per lesson.
   - Cached sentences are permanently retained in `out/_cache/tts/`. Subsequent builds for identical text are instantaneous.
2. **Sequential Builds**:
   - Never run `lv.py render` or `lv.py build` in parallel. Concurrent headless Edge instances and FFmpeg encoders will saturate RAM/GPU and cause OOM crashes.
3. **Git Index Preservation**:
   - Keep ~2749 staged files intact. Do not run any commands modifying git index or staging area.
