# Lab ESY L01 — Thao tác bit an toàn trên thanh ghi ngoại vi 8 bit

Từ thanh ghi ban đầu `reg = 0x12`, thực hiện tuần tự ba phép biến đổi an toàn: bật bit `3`, xoá bit `1`, rồi đảo bit `0`.
In đúng 1 dòng `set=... clr=... tog=...` (dạng `hex(...)`).

Chấm tự động:
```bash
bash labs/cham.sh ESY L01 duong_dan/bai_cua_ban.py
```
