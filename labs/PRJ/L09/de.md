# Dự án PRJ L09 — Bộ kiểm DFA 'ab' & tính trần song song Amdahl

Viết chương trình Python cài DFA 3 trạng thái nhận đúng các chuỗi chỉ chứa `'a','b'` kết thúc bằng `'ab'`, kiểm trên `"aaab"` và `"aba"`, và tính tăng tốc Amdahl `p=0.90` ở `8` nhân, in đúng 3 dòng:
1. `dfa_aaab=1 dfa_aba=0`
2. `amdahl_8cores=4.71`
3. `amdahl_inf=10.00`

Chấm tự động:
```bash
bash labs/cham.sh PRJ L09 duong_dan/bai_cua_ban.py
```
