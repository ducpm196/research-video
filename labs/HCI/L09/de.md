# Lab HCI L09 — Tính lợi ích vùng bấm 48 px so với 28 px ở khoảng cách D=300 px và tỉ lệ diện tích

Dùng công thức Fitts (`a = 0.1, b = 0.15, D = 300 px`) cho bề rộng nút `28 px` và `48 px`, đồng thời tính tỉ số diện tích nút vuông `(48*48) / (28*28)`.

Định dạng đầu ra (1 dòng):
`area_ratio=<2 chữ số>x t_28px=<3 chữ số>s t_48px=<3 chữ số>s`

Chấm tự động:
```bash
bash labs/cham.sh HCI L09 duong_dan/bai_cua_ban.py
```
