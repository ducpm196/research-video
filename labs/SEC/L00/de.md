# Lab SEC L00 — Ánh xạ mô hình đe doạ STRIDE sang thuộc tính an toàn

Đọc `stdin` `q1=<S|T|R|I|D|E> q2=<...> q3=<...>`. Tra cứu thuộc tính an toàn tiếng Anh tương ứng theo bảng 6 chữ cái STRIDE:
`S -> Authentication`, `T -> Integrity`, `R -> NonRepudiation`, `I -> Confidentiality`, `D -> Availability`, `E -> Authorization`.

In đúng 3 dòng: `stride_unique_props=<d>`, `info_disclosure=<prop>`, `tampering=<prop> spoofing=<prop>`.
