# Lab ROB L12 — Tính quãng dừng tối thiểu tính cả độ trễ điều khiển

Robot chạy ở `v = 2.0 m/s`, gia tốc phanh tối đa `a = 1.6 m/s^2` và độ trễ hệ thống `td = 0.25 s`. Tính tổng quãng dừng `v^2/(2*a) + v*td`.
In đúng 1 dòng `stop_dist_m=...` (3 chữ số).

Chấm tự động:
```bash
bash labs/cham.sh ROB L12 duong_dan/bai_cua_ban.py
```
