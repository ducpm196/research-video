# Lab DSY L12 [Mô phỏng phân tán] — Quét cột & nén Run-Length Encoding (RLE)

Viết chương trình Python cài hàm nén/giải RLE cho chuỗi `['VN']*6 + ['US']*3 + ['VN']*1` ra 3 cặp, và kiểm tra truy vấn 1 cột trong bảng 8 cột chỉ đọc `12.5%` tổng byte, in đúng 3 dòng:
1. `col_scan_pct=12.5%`
2. `rle_runs=3`
3. `rle_roundtrip_ok=1`

Chấm tự động:
```bash
bash labs/cham.sh DSY L12 duong_dan/bai_cua_ban.py
```
