# Lab LNX L05 — Kiểm tra lắng nghe cổng mạng và thứ tự phân giải /etc/hosts

Viết kịch bản Bash dùng Python/POSIX kiểm thử mở cổng lắng nghe thật, xác nhận thứ tự phân giải và in đúng 3 dòng:
1. `loopback_only=127.0.0.1`
2. `all_ifaces=0.0.0.0`
3. `hosts_before_dns=1`

Chấm tự động:
```bash
bash labs/cham.sh LNX L05 duong_dan/bai_cua_ban.sh
```
