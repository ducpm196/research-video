# Lab CPR L08 — Đóng gói trường bit và kiểm tệp nhị phân 16 byte

Viết chương trình C chuẩn C11 đóng gói `type=7, len=250` vào `uint16_t`, ghi 4 bản ghi 16 byte ra tệp `out.bin`, đọc lại rồi in đúng 2 dòng:
1. `packed=28922 type=7 len=250`
2. `bytes=64 count=4`

Chấm tự động:
```bash
bash labs/cham.sh CPR L08 duong_dan/bai_cua_ban.c
```
