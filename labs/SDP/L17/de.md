# Lab SDP L17 (Mô phỏng kiến trúc mô-đun hoá) — So số cạnh phụ thuộc trước/sau ranh giới

Viết chương trình Python tính số chiều gọi tối đa giữa `10` miền khi không có ranh giới (`10 * 9 = 90`) so với khi đi qua mặt tiền tập trung (tối đa `9` kênh công khai) và tỉ lệ giảm ghép cặp, in đúng 3 dòng:
1. `unbounded_edges=90`
2. `facade_edges=9`
3. `edge_reduction_pct=90.0%`

Chấm tự động:
```bash
bash labs/cham.sh SDP L17 duong_dan/bai_cua_ban.py
```
