# Lab DSC L12 — Đa cộng tuyến: tương quan 0.8 làm phình hệ số phóng đại phương sai (VIF) và sai số chuẩn

Tại tương quan `r = 0.8`, tính hệ số phóng đại phương sai `VIF = 1 / (1 - r^2)` và hệ số phình sai số chuẩn `căn(VIF)`.

Định dạng đầu ra:
`r=<1 chữ số> VIF=<2 chữ số> se_inflation=<2 chữ số>x`

Chấm tự động:
```bash
bash labs/cham.sh DSC L12 duong_dan/bai_cua_ban.py
```
