# Lab DSC L01 — Thang đo khoảng so với tỉ lệ: phép chia sai ở độ C so với độ Kelvin

Kiểm chứng phép chia sai `30°C` và `15°C` trên thang khoảng so với tỉ lệ đúng khi đổi sang thang Kelvin có số 0 tuyệt đối (`+273.15`).

Định dạng đầu ra:
`celsius_fake=<1 chữ số>x kelvin_real=<3 chữ số>x`

Chấm tự động:
```bash
bash labs/cham.sh DSC L01 duong_dan/bai_cua_ban.py
```
