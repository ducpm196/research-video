# Lab DSC L00 — Biến gây nhiễu trong dữ liệu quan sát so với phân chia ngẫu nhiên

Trong dữ liệu quan sát ở cửa hàng, nhóm đã xem quảng cáo có `75/120` khách mua hàng, nhóm chưa xem có `30/150` khách mua (`is_observational = 1`, không chia ngẫu nhiên). Tính hiệu chênh lệch quan sát và kiểm tra cờ cần phân chia ngẫu nhiên từ biến `is_observational`.

Định dạng đầu ra:
`obs_diff=<2 chữ số> needs_randomization=<1 hoặc 0>`

Chấm tự động:
```bash
bash labs/cham.sh DSC L00 duong_dan/bai_cua_ban.py
```
