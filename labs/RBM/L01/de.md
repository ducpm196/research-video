# Lab RBM L01 — Kiểm định quay 3D quanh X và Z theo hai thứ tự ngược nhau

Với vector `(1, 1, 0)`, hãy quay `90°` quanh `X` trước rồi `Z` sau (`p1 = Rz(Rx(v))`), và ngược lại (`p2 = Rx(Rz(v))`).
In đúng 1 dòng theo mẫu `Rz_after_Rx=(...) Rx_after_Rz=(...) equal=0/1`.

Chấm tự động:
```bash
bash labs/cham.sh RBM L01 duong_dan/bai_cua_ban.py
```
