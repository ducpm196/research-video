# Lab SWF L11 — Thuật toán hợp nhất ba chiều (Base, Branch A, Branch B)

In đúng 3 dòng: `merge_1_2_1=<v>`, `merge_1_3_3=<v>`, `merge_1_2_3=<v>`.
