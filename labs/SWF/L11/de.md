# Lab SWF L11 — Thuật toán hợp nhất ba chiều (Base, Branch A, Branch B)

Viết chương trình Python cài hàm `merge3(base, a, b)`: nếu `a == b` lấy `a`; nếu một nhánh không đổi so với `base` thì lấy nhánh kia; nếu cả hai sửa khác nhau báo `'CONFLICT'`, in đúng 3 dòng:
1. `merge_1_2_1=2`
2. `merge_1_3_3=3`
3. `merge_1_2_3=CONFLICT`

Chấm tự động:
```bash
bash labs/cham.sh SWF L11 duong_dan/bai_cua_ban.py
```
