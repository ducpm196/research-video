# Lab PLC L07 — Bao đóng giữ môi trường riêng: hai bộ cộng độc lập với step khác nhau

Cài hàm `make_adder(start, step)` trả về bao đóng mỗi lần gọi cộng thêm `step` vào biến đếm riêng bắt đầu từ `start`. Tạo `a1 = make_adder(20, 4)` gọi 2 lần và `a2 = make_adder(20, 7)` gọi 1 lần.

Định dạng đầu ra (1 dòng):
`a1=<danh sách 2 phần tử> a2=<số nguyên>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L07 duong_dan/bai_cua_ban.py
```
