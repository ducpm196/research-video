# Lab PLC L11 — Tối ưu gấp hằng số trên cả 4 phép +, -, *, // cho cây biểu thức

Cài hàm đệ quy `fold(node)` hỗ trợ cả 4 phép `'+'`, `'-'`, `'*'`, `'//'` trên cây biểu thức có lá số nguyên hoặc tên biến chuỗi, rồi rút gọn `('+', ('*', 3, 6), 'y')`.

Định dạng đầu ra (1 dòng):
`folded=<biểu thức rút gọn>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L11 duong_dan/bai_cua_ban.py
```
