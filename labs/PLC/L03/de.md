# Lab PLC L03 — Tính kết hợp trái của phép trừ trên bộ ba số [15, 6, 2]

So sánh kết quả gộp trái đúng luật của biểu thức `15 - 6 - 2` với cách gộp phải sai `15 - (6 - 2)`.

Định dạng đầu ra (1 dòng):
`left_assoc=<số nguyên> right_assoc=<số nguyên>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L03 duong_dan/bai_cua_ban.py
```
