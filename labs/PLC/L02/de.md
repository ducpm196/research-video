# Lab PLC L02 — Bộ phân tích đệ quy xuống theo tầng expr/term/atom cho hai biểu thức số học

Cài bộ phân tích đệ quy xuống theo đúng thứ tự ba tầng `expr`, `term`, `atom` (nhân `*` gắn chặt hơn cộng `+`), kiểm tra trên `'3+4*5'` và `'(3+4)*5'`.

Định dạng đầu ra (1 dòng):
`p1=<số nguyên> p2=<số nguyên>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L02 duong_dan/bai_cua_ban.py
```
