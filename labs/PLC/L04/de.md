# Lab PLC L04 — Mô phỏng chuỗi môi trường tra tên: phạm vi tĩnh so với phạm vi động

Cài hàm `lookup(env, name)` duyệt theo liên kết cha để so sánh tra tên theo phạm vi tĩnh (từ vị trí định nghĩa hàm với `x = 15`) và phạm vi động (theo ngăn xếp lời gọi với `x = 30`).

Định dạng đầu ra (1 dòng):
`static=<số nguyên> dynamic=<số nguyên>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L04 duong_dan/bai_cua_ban.py
```
