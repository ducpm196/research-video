# Lab PLC L12 — Cập nhật dữ liệu bất biến bằng bộ cố định (tuple)

Dùng kiểu bộ cố định (tuple) trong Python tạo `xs2 = xs1 + (35,)` từ `xs1 = (5, 15, 25)` và kiểm chứng `xs1` ban đầu vẫn nguyên vẹn.

Định dạng đầu ra (1 dòng):
`xs1=<bộ gốc> xs2=<bộ mới> unchanged=<0 hoặc 1>`

Chấm tự động:
```bash
bash labs/cham.sh PLC L12 duong_dan/bai_cua_ban.py
```
