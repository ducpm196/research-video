# Lab GFX L11 — Tính số mảnh tiết kiệm nhờ Early-Z trên khung 1280×720

Trên khung `1280 × 720`, tính tổng số mảnh tô ở mức `overdraw = 4` so với sau khi sắp vẽ gần–xa + Early-Z (`1×`) và phần trăm giảm tải.
In đúng 1 dòng `overdraw4=... earlyZ=... saved_pct=...%` (1 chữ số).

Chấm tự động:
```bash
bash labs/cham.sh GFX L11 duong_dan/bai_cua_ban.py
```
