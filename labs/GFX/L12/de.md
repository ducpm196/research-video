# Lab GFX L12 — Tính bước lượng tử độ sâu ở z=1000 m theo công thức đạo hàm đầy đủ

Ở khoảng cách `z = 1000.0 m`, `far = 10000.0 m`, `24 bit`, dùng công thức đạo hàm đầy đủ `(z^2*(f-n))/(f*n*2^24)` so sánh cấu hình `near = 0.02 m` với `near = 1.00 m`.
In đúng 1 dòng `dz_n002=...m dz_n100=...m` (2 chữ số).

Chấm tự động:
```bash
bash labs/cham.sh GFX L12 duong_dan/bai_cua_ban.py
```
