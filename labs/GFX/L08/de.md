# Lab GFX L08 — So sánh trộn màu thẳng trên sRGB với trộn tuyến tính đúng vật lý

Tính giá trị ánh sáng tuyến tính thực tế của byte `160` (khi trung bình cộng thẳng hai byte sRGB `80` và `240`) và tính byte sRGB đúng ứng với mức ánh sáng tuyến tính `0.25` theo công thức đổi hai đoạn chuẩn sRGB.
In đúng 1 dòng `wrong_lin=... right_srgb=...` (3 chữ số thập phân cho `wrong_lin`).

Chấm tự động:
```bash
bash labs/cham.sh GFX L08 duong_dan/bai_cua_ban.py
```
