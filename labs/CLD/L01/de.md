# Lab CLD L01 — So sánh bộ nhớ (RAM) nền giữa container và máy ảo

Đọc `stdin` `apps=<int> app_mb=<int> os_mb=<int>`. Tính RAM khi dùng chung nhân container so với chạy từng hệ điều hành VM và phần RAM dôi ra (GB, quy ước `1 GB = 1000 MB`).

In 3 dòng: `container_mb=<d>`, `vm_mb=<d>`, `vm_extra_gb=<.2f>`.
Chấm tự động: `bash labs/cham.sh CLD L01 duong_dan/bai_cua_ban.py`
