# Lab WEB L02 — Node.js thật: CSS Box Model và điểm ưu tiên bộ chọn (ID, Class, Tag)

Viết tập lệnh Node.js tính tổng bề rộng `width=200, padding=20, border=5` theo `content-box` và `border-box`, đồng thời so sánh độ ưu tiên `(id, class, tag)` giữa `#nav a` và `.menu .item a`, in đúng 3 dòng:
1. `content_box_w=250`
2. `border_box_w=200`
3. `id_beats_2class=1`

Chấm tự động:
```bash
bash labs/cham.sh WEB L02 duong_dan/bai_cua_ban.js
```
