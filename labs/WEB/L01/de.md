# Lab WEB L01 — Node.js thật: phân tích cây DOM từ chuỗi thẻ HTML

Viết tập lệnh Node.js dùng stack đọc các thẻ mở/đóng của `<ul><li>A</li><li>B<b>!</b></li></ul>` để đếm tổng số phần tử và độ sâu lớn nhất của cây DOM, in đúng 3 dòng:
1. `nodes=4`
2. `max_depth=3`
3. `valid_balanced=1`

Chấm tự động:
```bash
bash labs/cham.sh WEB L01 duong_dan/bai_cua_ban.js
```
