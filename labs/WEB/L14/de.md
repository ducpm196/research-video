# Lab WEB L14 — Node.js: tính tỉ lệ người dùng còn ở bản API cũ theo tuần

Đọc `stdin` `stay_rate=<f> w1=<n> w2=<n>`. Tính phần trăm còn lại sau `w1`, `w2` tuần theo `stay_rate^k` và số tuần tối thiểu để rơi xuống dưới `10%`.

In đúng 3 dòng: `week4_old_pct=<.1f>%`, `week8_old_pct=<.1f>%`, `weeks_under_10pct=<d>`.
Chấm tự động: `bash labs/cham.sh WEB L14 duong_dan/bai_cua_ban.js`
