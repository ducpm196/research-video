# Lab DVO L13 (Mô phỏng nhóm DORA) — So sánh tỉ lệ triển khai giữa nhóm thấp (Low) và cao nhất (Elite)

Viết chương trình Python chuẩn hoá khoảng `1 tháng..6 tháng` sang trung điểm `7 lần/năm` (nhóm thấp Low) so với `4 lần/ngày = 1 460 lần/năm` (nhóm cao nhất Elite) và tính bội số chênh lệch, in đúng 3 dòng:
1. `low_per_year=7`
2. `elite_per_year=1460`
3. `ratio_round=209x`
