# Lab EVT L00 — Giảm độ phức tạp kết nối nhờ kênh sự kiện

Viết chương trình Python tính số kết nối tối đa điểm–điểm nối từng cặp trong `N` dịch vụ so với nối qua 1 kênh sự kiện trung tâm cho hai quy mô `N = 8` và `N = 40` dịch vụ, đồng thời tính phần trăm giảm kết nối ở `N = 40`.

Định dạng đầu ra (3 dòng):
`p2p_8=<số> bus_8=<số>`
`p2p_40=<số> bus_40=<số>`
`reduction_40=<1 chữ số>%`

Chấm tự động:
```bash
bash labs/cham.sh EVT L00 duong_dan/bai_cua_ban.py
```
